Proyectos

PetCare

Backend · Java 21

Aplicacion web backend para la gestion integral del cuidado de mascotas. Reune toda la operacion de una veterinaria en una sola aplicacion: administrar usuarios con autenticacion y roles, registrar mascotas vinculadas a sus duenos con un historial clinico completo, y operar una tienda de productos.

Funcionalidades
  • Usuarios con autenticacion y roles.
  • Registro de mascotas con historial clinico (vacunas y medicamentos).
  • Gestion de turnos con profesionales veterinarios.
  • Tienda de productos con carrito de compras y metodos de pago.
  • Recordatorios y seguimiento del entrenamiento de las mascotas.
  • Estadisticas de ganancias y productos mas vendidos.
Stack tecnologico
Spring Boot 4 MySQL Arquitectura en capas DTOs Validacion y excepciones

LFM Nacional

Full Stack · Caracter privado

Plataforma web completa para la administracion de una liga de simracing de Assetto Corsa (proyecto universitario argentino de caracter privado). Gestiona pilotos, categorias, campeonatos, carreras e inscripciones, con ingesta automatica de sesiones reales desde el servidor del juego. Es el proyecto de mayor alcance: incluye ~28 entidades JPA, mas de 100 requisitos documentados (RF-001 a RF-100), diagramas UML y despliegue con Docker.

Funcionalidades
  • Gestion de pilotos, categorias, campeonatos, carreras e inscripciones.
  • Ingesta automatica de sesiones reales (JSON de clasificacion y carrera).
  • Sistema de rating Elo y Safety Rating recalculados automaticamente.
  • Incidentes con votacion de comisarios y sanciones apelables.
  • Setups con valoraciones, logros, recompensas y notificaciones.
  • Panel de administracion con roles USUARIO / ADMIN / COMISARIO.
Stack tecnologico
Spring Boot 4.1 Java 17 MySQL Spring Security JWT SCSS / JavaScript Docker

Pokemon

C · Consola

Gestor de mazos de cartas coleccionables estilo Pokemon en la consola. Dos jugadores cargan, muestran, eliminan e intercambian cartas entre distintos mazos, aplicando en la practica las estructuras de datos estudiadas en la materia: listas, pilas, colas y arboles binarios.

Funcionalidades
  • Carga, muestra, eliminacion e intercambio de cartas entre mazos.
  • Uso de listas, pilas, colas y arboles binarios para el manejo de datos.
  • Guardado de la informacion en archivos binarios.
  • Estadisticas del mazo y menu navegable dibujado con gotoxy.

Red Social en C

C · Consola · Trabajo grupal

Plataforma social/foro desarrollada como trabajo grupal de Programacion 1, construida en C para la consola. Su fin es ejercitar el manejo de estructuras y persistencia: permite registrar usuarios, publicar temas de interes, valorar contenidos y gestionar perfiles, todo guardado en archivos binarios.

Funcionalidades
  • Registro e inicio de sesion de usuarios.
  • Roles de administrador y usuario.
  • Publicacion de temas de interes con likes y puntajes.
  • Mensajeria interna y gestion de perfiles (alta/baja/modificacion).
  • Persistencia en archivos binarios y menus dibujados con gotoxy.
